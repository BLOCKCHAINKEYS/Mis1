# Burger Quest — Restaurant Empire (v6)

A mobile-and-desktop 3D burger restaurant game. Cook patties, assemble burgers, satisfy customers, earn money and expand to five locations.

The public website is a self-contained static HTML game (includes the 3D kitchen renderer, textures, interface and scripts). All player progress is stored locally in the browser. This repository is deployed as a static site.

## Run

Open `index.html` in a modern browser. For best phone compatibility and secure browser features, use the hosted HTTPS site.

## Privacy

No user accounts, telemetry, external API calls, or gameplay server; saves are stored in localStorage and may be exported manually.

## Release

Game public deployment still requires live smoke tests on the Render URL and physical-device acceptance before announcing a production launch.
